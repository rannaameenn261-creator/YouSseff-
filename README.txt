# Baby YouSsef — Rakan-style single page

ده الإصدار الـ single-page:
- مفيش تقسيم للـ pages.
- كل المحتوى في `index.html` وينزل بالـ scroll زي تجربة الموقع السابق.
- Baby-blue / cream watercolor atmosphere.
- Sections كثيرة: Hero, Details, Letter, Photo, Story, Memories, Ending.
- Music button ثابت فوق.
- Responsive للموبايل.

## ضيفي الصورة
ضعي صورة يوسف باسم:
`assets/photo.jpg`

## ضيفي الأغنية
ضعي الأغنية باسم:
`assets/youssef-song.mp3`

## GitHub Pages
ارفعي `index.html` + `style.css` + `script.js` + فولدر `assets` إلى الـ repository.
ثم:
Settings → Pages → Deploy from branch → main → / (root) → Save
